PEMPEK MUSI LINKTREE

Cara menjalankan:
1. Ekstrak folder ZIP.
2. Pastikan index.html dan folder assets berada dalam satu folder.
3. Buka index.html di browser, atau unggah seluruh isi folder ke hosting (Netlify, Vercel, GitHub Pages, cPanel).

Mengganti tautan:
Buka index.html, cari bagian:
const LINKS = { ... }

Tampilan:
- Responsive untuk HP, tablet, dan desktop.
- Font Plus Jakarta Sans + Montserrat (memerlukan koneksi internet).
- Ikon Lucide (memerlukan koneksi internet).
- Logo menggunakan assets/logo.png.
- Animasi masuk, hover, efek cahaya mengikuti pointer, dan feedback klik.
